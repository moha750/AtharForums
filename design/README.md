# مصادر الهوية

`athar-logo-source.svg` — الشعار كما صدّره Illustrator. منه اشتُقّت ملفات
`public/` الأربعة:

| الملف | كيف اشتُقّ |
|---|---|
| `athar-logo.svg` | المصدر بعد إزالة بيانات XMP |
| `athar-logo-dark.svg` | رُفعت إضاءة كل لون في فضاء OKLCH حتى يبلغ تباينًا ≥ ٣٫٢ مع سطح الوضع الداكن `#131f22`، مع زيادة التشبّع ١٫٣٥× حتى لا يبهت |
| `athar-mark.svg` | الرمز وحده — حُذفت عناصر الاسم والشعار النصّي والخط، وضُبط viewBox على حدود الرمز |
| `athar-mark-dark.svg` | الرمز من النسخة الداكنة |

الأخضر العميق في الشعار `#144e46` تباينه مع الخلفية الداكنة **١٫٩٦** فقط — أي
غير مقروء. ولهذا النسخة الداكنة ليست ترفًا.

عند تبديل الشعار مستقبلًا: أعد الاشتقاق لا تنسخ المصدر في الأربعة.
